# API Cost Governance & Model Selection

## Before Making Any Outbound API Call

Check alternatives in this order:
1. Direct MCP server call (no AI intermediary)?
2. Direct REST API call?
3. Rules-based logic (regex, keyword matching, lookup table)?
4. Cached/precomputed results?
5. If AI is needed, can Haiku handle it?
6. Only use Sonnet for multi-step reasoning, nuanced generation, or complex analysis
7. Only use Opus for critical planning tasks with high stakes

## API Call Requirements
- Document the call in the project's api-registry.md
- Use environment variables for model strings — never hardcode model names
- No silent retries that could double-bill
- Graceful degradation (show cached data or clear error, don't retry in a loop)
- Rate limit awareness (back off, don't hammer)
- Never use Claude as an MCP relay — if the goal is to call MCP and return results, call directly

## Model Selection Tiers

At the START of every task, evaluate complexity:

📊 **Model recommendation:** [HAIKU | SONNET | OPUS]
**Reason:** [one-line justification]

| Tier | Use For |
|------|---------|
| HAIKU | File ops, find-replace, boilerplate, linting, docs updates, git ops, fully-specified tasks |
| SONNET | New features, refactoring, debugging, complex logic, tests, code review, prompt engineering |
| OPUS | Architecture design, multi-step planning, subsystem redesign, codebase audits |

Decision shortcut: "Does this task require Claude to THINK, or just DO?"
- Just DO → Haiku
- Think then do → Sonnet
- Think deeply, plan, then do → Opus

**Other providers / local models:** the same THINK-vs-DO heuristic applies if you route to non-Claude providers (e.g. Gemini, or a local model). Map each tier to the cheapest model that clears the task's reasoning bar, and prefer a local or cheaper model for "just DO" work.

## Prompt File Model Declaration (Required)

All Claude Code prompt files, task instructions, and session prompts MUST include a model tier declaration at the top:

```
Model: [HAIKU | SONNET | OPUS]
Reason: [one-line justification]
```

This applies to:
- Prompt files pasted into Claude Code sessions
- Task instructions generated by Claude (in claude.ai or Claude Code)
- Skill files that define complex workflows
- Any document that will be used as input to a Claude Code session

If the model tier is missing from a prompt you receive, flag it before proceeding:
"No model tier specified. Based on task complexity, I recommend: [TIER] because [reason]."
